All colors, spacing and type styles below describe how the *existing* tokens are applied to the *new* screen/fields — they are not new tokens.

**Icon note (Claude's discretion, not blocking):** `lucide-react` is already a project dependency; add `export const CopyIcon = Copy;` to `components/icons.tsx` for the "Dublează în sezon nou" clone action (D-07). Until added, `PlusIcon` is an acceptable fallback consistent with the existing "Adaugă X" icon convention used across `PerioadaVacanta.tsx`/`TipuriAbonament.tsx`.

## Implementation Notes (screen structure)

### 1. New screen: `components/Sezoane/index.tsx` (ADMIN_CLUB + SUPER_ADMIN_FEDERATIE only)

Directly mirrors `PerioadaVacantaView` structure — same header pattern (`ArrowLeftIcon` back button + title + primary "Adaugă Sezon" CTA), same `Card`-per-row list, same empty state.

- **List of sezoane** (descending by `data_start`), each `Card` row shows:
  - `denumire` (bold, e.g. "Sezon 2026-2027") + `data_start — data_final` formatted `formatDataRo` (same helper already in `PerioadaVacanta.tsx`, reusable/portable)
  - **Status badge**: `Badge variant="green"` "Activ" when `activ=true`, no badge (or `Badge variant="slate"` "Arhivat") when `activ=false` — matches `Badge` component's existing 5-variant contract, no new variant needed
  - Edit/Delete icon buttons (admin only) — identical ghost-icon-button pattern from `PerioadaVacanta.tsx` (`Button variant="secondary" size="xs" ghost` for edit, `variant="danger" size="xs" ghost` for delete)
  - **"Activează" button** (only on non-active sezon rows, admin only) — `Button variant="secondary" size="sm"` — triggers the D-03 flow (deactivate current active + activate selected), see Copywriting Contract for the confirmation copy (this is a state-changing, non-reversible-by-accident action affecting facturare — gets a `ConfirmModal`, not silent)

- **Create/Edit modal** (`SezonFormModal.tsx`): identical shape to `PerioadaVacanta.tsx`'s `CrudModal` — `Input label="Denumire *"`, `Input type="date" label="Data Start *"`, `Input type="date" label="Data Final *"`, same inline date-order validation copy pattern (`error` prop on the second date field). On **create**, expose a checkbox/switch "Activează acest sezon acum" (`Switch` component, already in `ui.tsx`) — default **checked** for the very first sezon of a club, default **unchecked** for subsequent sezoane (avoids accidentally deactivating the current sezon on every add).

- **Empty state**: use `EmptyState` component (not the manual `Card` pattern in the older `PerioadaVacanta.tsx` — `EmptyState` is the canonical component introduced in Phase 25 and should be preferred going forward) with `icon={<CalendarDaysIcon className="h-10 w-10 text-[var(--t-text-muted)]" />}`.

### 2. `GrupaFormModal.tsx` extension

Add to the existing form (below `denumire`/`sala`/`club_id`/`locatie_id`, same `space-y-4` rhythm):
- **`Select label="Tip Grupă"`** with two options: `Permanentă` (value `permanent`, default) / `Per Sezon` (value `per_sezon`) — editable at any time, per D-04.
- **Conditional `Select label="Sezon"`** — rendered only when `tip_grupa === 'per_sezon'`, populated from the club's `sezoane` list, pre-selected to the club's active sezon. Uses the exact conditional-field show/hide pattern already used for `showAddLocatie` in this same file (state-gated block, no animation needed — instant show/hide is the established pattern here).
- Helper text under the `Select`, `Body` style, `var(--t-text-muted)`: *"Grupele permanente rămân active indiferent de sezon. Grupele per sezon se arhivează automat la trecerea la sezonul următor."*

### 3. `GrupaCard.tsx` extension

Add two small badges next to the existing card header (same row as `denumire`, using the existing `Badge` component — do not invent a new chip style):
- `Badge variant="blue"` "Permanentă" or `Badge variant="amber"` "Per Sezon" (always shown)
- `Badge variant="slate"` "Arhivată" (shown only when `grupa.arhivat === true`) — archived cards render with `opacity-60` on the whole `Card` (existing dimming pattern used elsewhere for inactive/disabled entities, e.g. produse `is_activ:false` rows) and the primary edit/delete actions are replaced by a single **"Dublează în sezon nou"** button (D-07) when the club has an active sezon different from the one the archived grupă belonged to.

### 4. `TipuriAbonament.tsx` extension

- Each tip-abonament row gains a **sezon label** (plain text, `text-xs text-[var(--t-text-muted)]`, e.g. "Sezon 2026-2027" or "— fără sezon (istoric)" for pre-existing rows with `sezon_id IS NULL`) — not a `Badge` (this is metadata, not a status), consistent with how `numar_membri`/`pret` are already displayed as plain inline text in this component.
- The existing hard-`delete()` action stays as-is **only** for tipuri never referenced by an emitted `plati` row; when a tip has ≥1 associated `plati.tip_abonament_id`, replace the delete button with a disabled state (`disabled`, `title="Tip folosit în facturi emise — nu poate fi șters"`) — mirrors the existing disabled-button-with-tooltip pattern already established in Phase 14 for "Șterge factură" on paid invoices (`PLF-04`).
- New tipuri created while a sezon is active are inserted with `sezon_id = sezonActivId` automatically (no new form field — silent, since D-09 ties this to the *system's* current sezon, not a user choice per row).

## Spacing Scale

Declared values (must be multiples of 4) — identical to the scale already in use across `ui.tsx` (Tailwind default spacing, no custom scale file):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps (`gap-1`), badge internal padding half-step |
| sm | 8px | Compact inline spacing (`gap-2`), badge row gaps, card header gaps |
| md | 16px | Default form field spacing (`space-y-4`), grid gaps (`gap-4`) between `Tip Grupă`/`Sezon` selects |
| lg | 24px | Modal/page section padding (`p-6` on `sm:` breakpoint), spacing between sezon list cards and page header |
| xl | 32px | Not used in this phase (no full-page multi-column layout) |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions: none. All buttons keep the existing 44px+ touch target via `size="sm"`/`size="md"` — icon-only ghost buttons (edit/delete on sezon rows) reuse the already-established `size="xs"` (32px) touch target from `PerioadaVacanta.tsx`, not a new exception.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 |
| Label | 12px (`text-xs`, uppercase, tracking-wide) | 700 (bold) | 1.4 |

| Display | not applicable — this phase introduces no page-level hero/display text |

Existing reused components (`Badge` uses `font-bold`/700 at 10px, `Button` uses `font-medium`/500) keep their own pre-existing styling unchanged — this contract governs only the new content authored for this phase (sezon list rows, the two new grupă badges, the sezon label on tipuri-abonament rows, helper/error copy), which sticks to exactly 2 weights: 400 and 700 (the `Heading` 600/semibold is inherited verbatim from the existing `PerioadaVacantaView` title and is not a new weight introduced by this phase's own authored content).

## Color

This project uses a CSS-variable theming system (`index.css`, `--t-*` tokens, dark-mode default, 20 selectable themes) rather than fixed hex — so the contract is expressed in token roles, which resolve correctly under every installed theme.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--t-bg)` (default theme: `#020617`) | Page/app background behind the Sezoane screen and all modals |
| Secondary (30%) | `var(--t-surface)` / `var(--t-surface-2)` (default: `#0f172a` / `#1e293b`) | `Card` surfaces (sezon rows, grupă cards), modal header/footer bars, input backgrounds (`var(--t-input-bg)`) |
| Accent (10%) | `var(--t-primary)` (default: `#3b82f6`, blue) | Reserved for: primary submit buttons ("Salvează Sezon", "Adaugă Sezon"), input focus rings, the "Per Sezon" grupă badge is **not** accent-colored (uses `amber` per Badge contract below) — accent stays reserved strictly for CTAs and focus states, never decorative badges |
| Destructive | `var(--t-status-danger)` | Reserved for: delete sezon button/icon, delete grupă button/icon (unchanged from existing pattern), the disabled-delete tooltip text on tipuri-abonament rows referenced by emitted facturi. **Not** used for the "Arhivat" badge (uses neutral `slate`, since archiving is an expected lifecycle state, not an error) |

Badge variant assignments for this phase (using the existing 5-variant `Badge` contract — `green`/`red`/`amber`/`blue`/`slate` — no new variants introduced):
- Sezon "Activ" → `green`
- Sezon "Arhivat" (inactive, past) → `slate`
- Grupă "Permanentă" → `blue`
- Grupă "Per Sezon" → `amber`
- Grupă "Arhivată" → `slate`

Accent reserved for: primary CTA buttons (Adaugă/Salvează Sezon, Activează, Dublează în sezon nou), input focus rings. Never used decoratively on badges or list rows.
