`genereaza_taxe_anuale(p_club_id uuid, p_tip text, p_an integer, p_sportiv_ids uuid[] DEFAULT NULL) RETURNS jsonb` (TA-06):
1. Validari: p_tip IN ('FRQKD','FRAM') altfel RAISE 'Tip de taxă invalid' ERRCODE '22023'; p_an intre 2020 si 2100 altfel '22023'; p_club_id NOT NULL altfel '22023'; daca p_sportiv_ids nu e NULL si are peste 2000 elemente -> '22023'.
2. IF NOT public.poate_gestiona_taxe_club(p_club_id) THEN RAISE 'Acces refuzat: doar administratorul clubului poate genera taxele anuale' USING ERRCODE = '42501'.
3. Lista tinta: daca p_sportiv_ids IS NULL -> toti sportivii cu club_id = p_club_id AND status = 'Activ' (generare in masa); altfel DISTINCT din array. Pentru lista explicita, orice id care nu exista sau nu are club_id = p_club_id primeste rezultatul 'refuzat' (fara efecte, fara sa-i dezvalui datele).
4. Pentru fiecare sportiv valid: v_rez := public.activeaza_taxa_sportiv(id, p_tip, p_an); plata_id-ul se citeste din vize_sportivi (sportiv_id, an, tip) dupa apel.
5. RETURN jsonb_build_object('facturat', n, 'in_asteptare', n, 'exista', n, 'refuzat', n, 'detalii', jsonb_agg de {sportiv_id, rezultat, plata_id}). 'fara_club' / 'sportiv_inexistent' se numara la refuzat.
Regenerarea este idempotenta prin gate-ul vizei (scutitii si sportivii activati la alt club ies 'exista').

`seteaza_scutire_taxa(p_sportiv_id uuid, p_tip text, p_an integer, p_scutit boolean, p_motiv text DEFAULT NULL) RETURNS jsonb` (TA-07):
1. Validari tip/an ca mai sus; daca p_scutit = true si btrim(coalesce(p_motiv,'')) = '' -> RAISE 'Motivul scutirii este obligatoriu' ERRCODE '22023'; length(p_motiv) > 500 -> '22023'.
2. SELECT viza (sportiv_id, an, tip) FOR UPDATE. Clubul de verificat = viza.club_id daca viza exista, altfel sportivi.club_id (sportiv inexistent -> 'P0002'). IF NOT poate_gestiona_taxe_club(club) -> '42501' cu mesaj 'Acces refuzat: taxa aparține altui club'.
3. Ramura p_scutit = true:
   a. Daca exista rand in decont_sportivi pe (sportiv_id, an, tip) -> RAISE 'Taxa a fost deja virată federației — scutirea nu mai este posibilă' ERRCODE 'P0001'.
   b. Daca viza are plata_id: citeste factura; daca status IN ('Achitat','Achitat Parțial') SAU exista tranzactii cu plata_id = ANY(plata_ids) -> RAISE 'Factura taxei are încasări — anulează întâi încasarea' ERRCODE 'P0001'; altfel daca status <> 'Anulat' -> UPDATE plati SET status = 'Anulat' (pastreaza randul pentru audit; daca auditul arata o coloana de observatii/motiv anulare, completeaza 'Scutire: ' || motiv), retine plata_anulata_id. plata_id ramane pe viza ca referinta istorica.
   c. Daca viza nu exista: INSERT viza (sportiv_id, an, tip, club_id = sportivi.club_id, status_viza 'Activ', data_platii CURRENT_DATE, scutit true, motiv_scutire, scutit_de auth.uid(), scutit_la now()) fara factura.
   d. Altfel UPDATE viza SET scutit = true, motiv_scutire = btrim(p_motiv), scutit_de = auth.uid(), scutit_la = now().
   e. RETURN {stare: 'scutit', plata_id: NULL, plata_anulata_id}.
4. Ramura p_scutit = false: daca viza nu exista sau nu e scutita -> RETURN starea curenta fara efecte. Altfel UPDATE viza SET scutit = false, motiv_scutire = NULL, scutit_de = NULL, scutit_la = NULL, plata_id = NULL (factura anulata ramane in plati ca istoric), apoi v_plata := public.factureaza_viza_taxa(viza.id) -> RETURN {stare: 'facturat' sau 'in_asteptare', plata_id: v_plata}.
