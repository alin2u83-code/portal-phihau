## Assumptions (planner, from 45-RESEARCH.md recommendations)

- A6 The reconstruction lives only here (TS); the RPC validates ids and copies (research A1, Anti-pattern "reconstruire in doua locuri").
- A7 Same-type clone (tip tinta == tip sursa) produces no compatibility warnings: competition J1SV is `tehnica` and legitimately carries a `giao_dau` probe. D-11/D-12 warnings apply only when the type changes.
- A9 Default name: every standalone 4-digit year 19xx/20xx in the source name is replaced by year + 1 (e.g. "Copii si Juniori (Iasi 2025)" -> "... 2026"); if the name has no year, " (copie)" is appended. The super admin edits it; uniqueness is still validated.
- A10 Duplicate-name check compares lower-case, trimmed names (same rule as the RPC).
- Split parent whose `categorii_fuzionate_din` lists no existing category: the children cannot be identified, so the active variants are kept: the parent is excluded and a warning is produced (D-08 "se ia varianta activa").
- Fusion result that was later split (este_fuzionata = true AND status 'impartita'): its link to the fusion sources was overwritten, so it is excluded (its children too); its sources, if any, stay included; a warning is produced (D-08). Not present in live data; covered by a fixture.
