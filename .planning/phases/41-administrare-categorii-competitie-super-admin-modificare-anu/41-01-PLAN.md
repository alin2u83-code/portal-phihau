<objective>
Create the database contract for Phase 41: one atomic SECURITY DEFINER RPC that applies category operations (anulare, fuziune, impartire, mutare/realocare) with a super-admin guard, drift detection and no deletes. Wave 0 live verification comes first (D-12).

Purpose: client-side multi-step writes (the old FuzionariPanel style) leave partial states and DELETE categories with history. A single plpgsql transaction validates the preview's explicit mapping and applies it (D-03), keeps cancelled categories as "Fara categorie" holders (D-04, D-07), blocks only on `finalizata` (D-09) and reports cancelled fees (D-08).
Output: migration file (written, NOT applied; applying is 41-04 after explicit OK) and the ACL allowlist entry.
