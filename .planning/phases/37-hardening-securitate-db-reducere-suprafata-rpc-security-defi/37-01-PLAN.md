Drepturi in aceeasi migratie: `REVOKE ALL ON FUNCTION public.acl_functii_snapshot() FROM PUBLIC, anon, authenticated;` apoi `GRANT EXECUTE ON FUNCTION public.acl_functii_snapshot() TO service_role;` apoi `NOTIFY pgrst, 'reload schema';`.
