# Quick Task 260924-04t: Integrare filtru sezon in Grupe, Orar si profil sportiv

**Data:** 2026-09-24

## Cerinta

Sistemul de sezoane (`sezoane`, `useSezonActiv`) exista deja in cod, dar filtrarea pe sezon nu era consistenta:

1. Tab **Grupe** (`components/Grupe/index.tsx`) avea filtru sezon doar tranzitoriu — activ doar cand venea navigare din Sezoane cu `viewParams.sezonId`; fara selector persistent.
2. **Orar** (`components/Grupe/ProgramAntrenamenteManagement.tsx`) nu avea nicio legatura cu sezoane — filtra doar zi/grupa/club.
3. Dropdown **Grupă** din profilul sportivului (`components/Sportivi/SportivFormFields.tsx`) arata toate grupele clubului, inclusiv cele din sezoane vechi/arhivate.
4. Cardurile de grupa (`GrupaCard.tsx`, `GrupaDetailView.tsx`) aveau badge generic "Per Sezon" fara denumirea sezonului.

## Fisiere modificate

- `components/Grupe/index.tsx` — dropdown persistent "Sezon" (implicit = sezon activ), inlocuieste banner-ul tranzitoriu; grupe permanente mereu vizibile, `per_sezon` doar din sezonul selectat; `sezonDenumire` calculat si trecut la `GrupaCard`.
- `components/Grupe/GrupaCard.tsx` — prop nou `sezonDenumire`; badge amber arata "Sezon: {denumire}" cand exista, altfel fallback "Per Sezon".
- `components/Grupe/GrupaDetailView.tsx` — badge sezon in header langa denumirea grupei, folosind `useSezoane(grupa.club_id)` (aceeasi queryKey ca in `TabIstoricMembri`, deduplicat de React Query — zero request suplimentar).
- `components/Grupe/ProgramAntrenamenteManagement.tsx` — dropdown "Filtrează după sezon" langa filtrele existente (zi/grupa/club); antrenamentele se leaga de grupa lor prin `grupaMap` (din `filteredData.grupe`, deja disponibil in context) — view-ul `vedere_cluburi_program_antrenamente` nu expune `sezon_id`/`tip_grupa` direct, deci maparea s-a facut client-side, fara migrare SQL noua.
- `components/Sportivi/SportivFormFields.tsx` — dropdown Grupă filtrat: grupe permanente + `per_sezon` doar din sezonul activ al clubului; grupa deja asignata sportivului ramane vizibila chiar daca apartine unui sezon vechi (evita dezasignare silentioasa la editare).

## Reguli aplicate consecvent

- Grupele `tip_grupa === 'permanent'` sunt **mereu** vizibile, indiferent de filtrul de sezon (decizie confirmata in intake).
- Filtrul de sezon e ascuns complet cand clubul nu are niciun sezon definit (`sezoane.length === 0`) — zero regresie pt cluburi fara sezoane.
- Fara migrari DB noi, fara atingere `useDataProvider.ts`, `contexts/DataContext.tsx`, `types.ts` (tipurile `tip_grupa`/`sezon_id` existau deja optional pe `Grupa`).
