<objective>
Enforce the FRAM rule in the wizard's athlete selection (D-04) with the super admin exception confirmed explicitly (D-05). UI is UX only; the DB trigger from 42-01 is the gate.

Purpose: the club representative must see before saving that an athlete cannot be enrolled, and why. The super admin decision is a deliberate act per athlete (confirmation), logged in audit by the DB trigger when saved.
Design choice: the super admin flag is derived locally with the project pattern `usePermissions(useData().activeRoleContext)` (as in components/Competitii/StagiiCompetitii.tsx:180), so no new prop crosses the wizard (in the extern zone the context role is never SUPER_ADMIN_FEDERATIE). The FRAM data source is the `vizeSportivi` prop the wizard already receives; 42-08 switches what index.tsx passes into it.
Output: Pas1 blocking + confirm, new eligibility status and badge.
</objective>
