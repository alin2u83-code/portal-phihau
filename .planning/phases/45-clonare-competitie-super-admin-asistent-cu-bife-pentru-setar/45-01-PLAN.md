<objective>
Write the database contract for Phase 45: one atomic SECURITY DEFINER RPC `competitie_cloneaza` that copies a competition's settings, probes and an explicit list of its categories into a NEW draft competition, guarded by `is_super_admin()`. A read-only live check comes first.

Purpose: today competitions are created by 3 successive client inserts (CompetitieForm / MigrareModal / GenerareSabloaneModal) with no transaction; a clone must never be half-created (D-04). The client computes WHICH categories form the initial structure (45-02, single implementation); the server validates that every id belongs to the source and copies them remapped and renumbered (D-06, D-07, D-09).
Output: migration file (written, NOT applied; applying is 45-03 after explicit OK) and the ACL allowlist entry.
</objective>

## Assumptions (planner, from 45-RESEARCH.md recommendations; Claude's discretion per CONTEXT)

- A1 Target type is a parameter (`p_tip`), restricted to tehnica / giao_dau / cvd (no `stagiu`: the competitii CHECK rejects it). Needed for D-11 (cross-type clone).
- A2 Settings box unticked (`p_setari = false`): locatie and organizator NULL; config_taxe = the CompetitieForm defaults {"individual_tehnica":80,"individual_cvd":80,"echipa_seniori":120,"echipa_juniori":150,"cvd_echipa":80,"currency":"RON"}; taxa_individual 80; taxa_echipa 120; fram_obligatoriu false. Avoids a silent 0 fee (research Pitfall 4). D-10 (as-is copy) applies when the box is ticked.
- A3 D-03 reading: categories require probes, so a non-empty `p_categorii` with `p_probe = false` is refused (22023); probes alone (empty `p_categorii`) are allowed.
- A4 search_path: `SET search_path = pg_catalog, public` with every object qualified `public.`. D-04 says "follow the categorii_aplica_operatie model"; its text says `public, pg_catalog`, but the model function itself was hardened to `pg_catalog, public` by 20261115a (security audit SEC-41-03). Using the older order would reintroduce that finding.
- A5 New status is `'draft'` (UI label "Schita"); `'schita'` would violate the CHECK (research Pitfall 2).
- A6 Initial-structure reconstruction (D-06/D-08) is computed ONCE, in TypeScript (45-02); the RPC only validates that every id in `p_categorii` belongs to `p_sursa` and copies them. No server-side duplicate of the algorithm.
- A7 Name uniqueness: case-insensitive, trimmed, across all competitions, checked under a transaction advisory lock (two super admins / double click).
- A8 `observatii` of the new competition holds only the clone note (D-16); the source's own observatii are not copied. No drift parameter (`p_asteptat`) since the source is normally finalized (research Open Question 4).
