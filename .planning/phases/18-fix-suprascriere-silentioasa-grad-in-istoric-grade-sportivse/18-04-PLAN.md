## E. Verificarea fluxului real (Task 2)

Inlocuieste `<ID_SESIUNE>` cu id-ul sesiunii de examen folosite la verificarea umana.

```sql
SELECT
    se.id            AS sesiune_id,
    se.data          AS data_sesiune,
    s.nume, s.prenume,
    g_ist.nume       AS grad_din_istoric,
    ig.data_obtinere,
    (ig.data_obtinere = se.data) AS data_corecta,
    g_act.nume       AS grad_actual_sportiv,
    g_act.ordine     AS ordine_actuala,
    g_max.ordine     AS ordine_max_din_istoric,
    (s.grad_actual_id = g_max.id) AS grad_actual_corect,
    s.metoda_selectie_grad
FROM public.istoric_grade ig
JOIN public.sesiuni_examene se ON se.id = ig.sesiune_examen_id
JOIN public.sportivi s  ON s.id = ig.sportiv_id
JOIN public.grade g_ist ON g_ist.id = ig.grad_id
LEFT JOIN public.grade g_act ON g_act.id = s.grad_actual_id
LEFT JOIN LATERAL (
    SELECT g.id, g.ordine
    FROM public.istoric_grade i2 JOIN public.grade g ON g.id = i2.grad_id
    WHERE i2.sportiv_id = s.id
    ORDER BY g.ordine DESC LIMIT 1
) g_max ON TRUE
WHERE ig.sesiune_examen_id = '<ID_SESIUNE>'
ORDER BY s.nume;
```

Cerinta: pe randul (randurile) atinse de fluxul real, `data_corecta = true` SI `grad_actual_corect = true` SI `metoda_selectie_grad = 'automat'`.
