<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/SPA → Supabase Auth (GoTrue) | Enrollment + verify TOTP; sursa de adevar a AAL este sesiunea semnata, nu un flag app-level |
| user cu parola compromisa → date sensibile (financiar/medical) | MFA ca al doilea factor pentru rolurile privilegiate |
| SPA state (client) → enforcement | Gate-ul de randare este UX/defense, nu granita de securitate (RLS ramane gardul real) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-03 | Spoofing | login admin cu parola furata fara al doilea factor | mitigate | Enforcement TOTP pentru ADMIN_CLUB/SUPER_ADMIN_FEDERATIE via getAuthenticatorAssuranceLevel (Task 2) |
| T-17-04 | Information Disclosure | flash de continut protejat inainte de redirect | mitigate | Render-gate real in App.tsx: MartialArtsSkeleton in loc de AppLayout cat timp !mfaChecked (Task 2, Pitfall 2) |
| T-17-05 | Elevation of Privilege | bypass client-side al redirect-ului setup-mfa (tampering SPA state) | accept | App-tier gating e UX-only per conventia proiectului; RLS ramane gardul; DB-level aal2 RLS policy e out-of-scope explicit in CONTEXT.md (defense-in-depth viitor) |
| T-17-06 | Denial of Service | eroare retea la check-ul AAL blocheaza toti adminii | accept | Fail-open deliberat documentat (Pitfall 3): eroare de retea nu blocheaza accesul; NU inversa in fail-closed fara re-discutie cu userul |
