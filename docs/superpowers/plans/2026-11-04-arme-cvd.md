# Selecție arme CVD per sportiv — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adminul clubului alege armele fiecărui sportiv CVD (salvate, editabile), apoi îl înscrie separat pe fiecare armă, cu formele filtrate pe armă; Giao Dau și Song Luyen respectă armele alese.

**Architecture:** Nomenclator `arme` + legături în DB (migrare), reguli pure într-un modul testabil fără UI (`utils/armeCvd.ts`), un serviciu Supabase + un pas nou „Arme" la începutul wizardului CVD, apoi Pas2/Pas4/Giao Dau/Song Luyen refăcute să lucreze pe `(sportiv, armă)`. Competițiile non-CVD rămân neatinse.

**Tech Stack:** React 18, TypeScript, Tailwind, Supabase (Postgres + RLS), `components/ui.tsx`. Teste pure: `npx tsx tests/armeCvd_reguli.ts` (node:assert).

**Spec:** `docs/superpowers/specs/2026-11-04-arme-cvd-design.md`

## Global Constraints

- Fără librării noi. UI doar din `components/ui.tsx` (nu Shadcn/MUI). Filtrare client-side pe datele încărcate; singurele query-uri noi sunt cele pentru arme.
- Toate tipurile noi în `types.ts` (fișier unic). Limbă: română pentru domeniu, engleză pentru hook-uri/pattern-uri.
- Servicii returnează `{ data, error }`, nu aruncă. Erori UI prin `useError().showError`.
- Competiții `tip = 'cvd'` doar; `tehnica` și `giao_dau` (QKD) neschimbate.
- O armă per categorie: unicitatea `(categorie_id, sportiv_id)` din DB rămâne. Un rând `inscrieri_competitie` per armă; o taxă per înscriere (80 lei Giao Dau CVD, neschimbat).
- Giao Dau CVD: arme permise = `Bong, Song Cot, Moc Can, Moc Guom, Long Gian`. `Phuc Su Dao` și `Cuu Khuc` se elimină (`arma_id` rămâne NULL, nu apar).
- Restricții: lamă + articulată interzis; grade (`grad.ordine < 19`) la Bong interzis cu Long Gian/Song Cot/Moc Can. Stagii și „max 3 sportivi per club" = doar avertisment.
- Editare armă: doar `ADMIN_CLUB`/`SUPER_ADMIN_FEDERATIE`, cât `competitie.status = 'inscrieri_deschise'`; INSTRUCTOR doar citește. Înscriere cu `taxa_achitata = true` = blocată (lacăt).
- `supabase/` e în `.gitignore`: migrările se adaugă cu `git add -f`. Migrarea se aplică pe DB live (`wuhidifzsutwgdfkwhmd`) doar cu OK explicit al utilizatorului; datele sunt reale.
- Fără push/commit fără cerere; fiecare task se încheie cu `npx tsc --noEmit` (0 erori pe Competitii) și un commit local la cererea utilizatorului.

## Review Focus

- Sportiv fără nicio armă aleasă ajunge la Thao Lo → mesaj clar, nu sărit în tăcere (Task 5).
- Două arme alese care duc la aceeași categorie → a doua blocată cu motiv, nu eroare la salvare din cauza unicității (Task 2, 5).
- Debifarea unei arme cu înscriere plătită → refuz, nimic șters (Task 6).
- Sportiv promovat între implicit și competiție → arma pierdută apare estompată cu avertisment, nu dispare (Task 2, 4).
- Sportiv inactiv cu înscriere salvată → rămâne în sumar și în pasul Arme, doar citire (Task 4, 6).
