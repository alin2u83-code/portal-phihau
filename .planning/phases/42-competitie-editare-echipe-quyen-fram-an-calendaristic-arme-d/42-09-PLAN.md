Purpose: members/arma editing already exists (InscriereModal edit mode, made safe in 42-07); quyen of an existing individual enrollment and category moves for the representative do not exist yet. D-09 "de rezolvat": there is no persisted "de rezolvat" store in the app. Both existing mechanisms compute their entries from data already available: ItemDeRezolvat + BannerDeRezolvat (components/Competitii/InscriereClubWizard/BannerDeRezolvat.tsx) inside the competition, and ProblemaDeRezolvat + DeRezolvatCard (components/DeRezolvatCard.tsx, federation list built in AdminMasterMap.tsx:81-86) on the dashboard. The persisted evidence of a move is the audit trail: audit_trigger_fn stores the full old and new row of every UPDATE on inscrieri_competitie / echipe_competitie (20261111d), so the entries are computed from audit_log and shown with BannerDeRezolvat in the competition's Financiar tab (super admin surface, where fees are settled). Member edits do not change fees (one fee per team, construiesteRanduriPlata), so only category moves can produce an entry. The dashboard card is not extended (it would need a cross-competition audit query).
Output: new modal, D-09 helper + tests, Financiar "De rezolvat" banner, InscrieriView entry points, canEditEchipe, docs section, verification record.
