## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pg_cron / Edge Function (`service_role`) → functii SQL | Context fara `auth.uid()` si fara headerul `active-role-context-id`; RLS nu se aplica la fel ca pentru un utilizator |
| client autentificat (PostgREST RPC) → `add_sms_to_queue` | Input controlat de utilizator: `p_club_id`, `p_sportiv_id` — trebuie sa ramana gardat de `has_access_to_club` |
| `sms_queue` → gateway SMS extern | Iesire catre lumea reala (cost financiar, mesaje catre minori) — in acest plan NU e activa (fara job de procesare) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-30-01-SC | Tampering | npm/pip/cargo installs | accept | Zero pachete noi in aceasta faza (30-RESEARCH.md § Package Legitimacy Audit) — nu se ruleaza niciun install |
