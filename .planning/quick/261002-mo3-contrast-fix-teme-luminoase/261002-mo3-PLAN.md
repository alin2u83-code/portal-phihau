# Quick 261002-mo3 — Contrast teme luminoase

Cauza: clase Tailwind hardcodate (slate-*, text-white, amber/emerald pale) ignora tema.
Abordare centrala (nu 243 fisiere):
1. tailwind.config.js: paleta slate (+ nuante pale 300/400 ale culorilor de accent) prin CSS vars `rgb(var(--x) / <alpha-value>)`.
2. index.css: valori default = paleta Tailwind; `[data-theme-mode="light"]` inverseaza slate si inchide accentele pale; `aside`/`footer` reseteaza la paleta dark (sidebar/footer raman inchise).
3. lib/themes.ts applyTheme: seteaza `data-theme-mode` din luminanta `theme.bg`.
4. text-white fara bg-* propriu -> text inchis in mod light.
Verificare: audit contrast WCAG AA in Chrome pe fiecare tema luminoasa; tsc/build.
