Sectiunea 1 — `inregistreaza_plata_federatie(...) RETURNS jsonb` (TA-08):
1. Validari ERRCODE '22023' cu mesaje romanesti: p_tip IN ('FRQKD','FRAM'); p_an 2020..2100; p_metoda_plata IN ('Cash','Transfer Bancar','Revolut'); p_sportiv_ids nenul si cu cel putin un element ('Selectează cel puțin un sportiv'); maxim 2000 elemente; p_data_plata NULL -> CURRENT_DATE, iar p_data_plata > CURRENT_DATE + 1 -> 'Data plății nu poate fi în viitor'; daca p_dovada_url nu e NULL trebuie sa inceapa cu 'public/' || p_club_id::text || '/' (impiedica legarea fisierului altui club); length(p_observatii) <= 1000.
2. IF NOT public.poate_gestiona_taxe_club(p_club_id) -> RAISE 'Acces refuzat: nu poți înregistra plăți către federație pentru acest club' ERRCODE '42501'.
3. v_ids := array DISTINCT din p_sportiv_ids. Lock: SELECT ... FROM vize_sportivi WHERE sportiv_id = ANY(v_ids) AND an = p_an AND tip = p_tip FOR UPDATE.
4. Validare atomica: un sportiv e INVALID daca nu are viza (an, tip), viza.club_id <> p_club_id, viza.scutit, viza.plata_id IS NULL (in asteptare), factura lipseste sau are status 'Anulat', sau exista deja in decont_sportivi pe (sportiv_id, an, tip). Daca exista invalizi -> RAISE 'Următorii sportivi nu pot fi incluși în plata către federație (taxă nefacturată, scutită, din alt club sau deja virată): %' ERRCODE 'P0001', unde lista contine nume + prenume DOAR pentru sportivii cu sportivi.club_id = p_club_id si id-ul brut pentru restul (nu dezvalui nume din alte cluburi).
5. v_total := SUM(plati.suma) a facturilor legate prin vize.plata_id; v_n := numarul de sportivi. Factura sportivului poate fi Neachitata — este permis (CONTEXT pas 4: apare in banner, nu blocheaza).
6. INSERT INTO deconturi_federatie (club_id = p_club_id, an_fiscal = p_an, tip_activitate = p_tip, suma_totala = v_total, nr_participanti = v_n, status_plata = 'Platit', metoda_plata = p_metoda_plata, confirmata_federatie = true, data_decont = p_data_plata, data_generare = now(), dovada_transfer_url = p_dovada_url, creat_de = auth.uid(), observatii = p_observatii) RETURNING id.
7. INSERT INTO decont_sportivi (decont_id, sportiv_id, an, tip, plata_id, suma) pentru fiecare sportiv valid (suma = plati.suma). O cursa concurenta loveste indexul unic -> 23505 (propagat; clientul il traduce).
8. RETURN jsonb_build_object('decont_id', ..., 'suma_totala', v_total, 'nr_participanti', v_n).

Sectiunea 2 — `raport_taxe_anuale_cluburi(p_tip text, p_an integer) RETURNS TABLE(...)` STABLE (TA-12, TA-07): validare tip/an (22023). Pornind din cluburi c, filtrat la c.id pentru care public.poate_gestiona_taxe_club(c.id) (federatia vede toate cluburile, inclusiv cele cu 0 taxe; ADMIN_CLUB doar clubul propriu; INSTRUCTOR nimic), LEFT JOIN agregari pe vize_sportivi v (v.club_id = c.id AND v.tip = p_tip AND v.an = p_an) cu LEFT JOIN plati p ON p.id = v.plata_id:
nr_sportivi = count vize; nr_scutiti = count scutit; nr_in_asteptare = count (plata_id NULL AND NOT scutit); nr_facturati = count (NOT scutit AND p.id NOT NULL AND p.status <> 'Anulat'); suma_facturata = SUM p.suma pe aceleasi randuri; suma_achitata_club = SUM p.suma unde p.status = 'Achitat'; suma_restanta_club = suma_facturata - suma_achitata_club; nr_virati / suma_virata = count / SUM(ds.suma) din decont_sportivi ds JOIN deconturi_federatie d ON d.id = ds.decont_id WHERE d.club_id = c.id AND ds.tip = p_tip AND ds.an = p_an AND d.status_plata = 'Platit'; suma_de_virat = suma_facturata - suma_virata. Toate sumele COALESCE 0. ORDER BY club_nume.
