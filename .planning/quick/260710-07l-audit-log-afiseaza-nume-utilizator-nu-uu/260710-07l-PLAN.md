  <name>Task 3: Serviciu — derivare sesiuni si trafic din LOGIN/LOGOUT</name>
  <files>types.ts, services/auditLogService.ts</files>
  <action>
types.ts (langa AuditLogEntry, ~linia 565): adauga
`export interface LoginSession { user_id: string; login_at: string; logout_at: string | null; durata_secunde: number | null; }`
`export interface TraficProfil { user_id: string; nr_sesiuni: number; timp_total_secunde: number; }`

services/auditLogService.ts:
1. `fetchSessionEvents(filters: { userId?: string; dataStart?: string; dataEnd?: string; limit?: number }): Promise<{ data: AuditLogEntry[]; error: any }>` — query `audit_log` cu `.in('operatie', ['LOGIN','LOGOUT'])`, `.order('created_at', { ascending: true })` (cronologic ascendent — necesar pentru pairing), aplica filtrele userId/dataStart/dataEnd la fel ca fetchAuditLog, `.limit(filters.limit ?? 1000)`. Returneaza {data, error} ca fetchAuditLog.
2. `deriveSessions(events: AuditLogEntry[]): LoginSession[]` — functie PURA. Grupeaza pe user_id, pentru fiecare user parcurge evenimentele in ordine cronologica: la LOGIN deschide o sesiune (login_at); la LOGOUT inchide sesiunea deschisa (durata_secunde = round((logout - login)/1000)); daca apare alt LOGIN cat o sesiune e deschisa (fara LOGOUT intre), inchide precedenta cu logout_at=null si durata_secunde=null (necunoscuta) apoi deschide una noua; la final orice sesiune ramasa deschisa => logout_at=null, durata_secunde=null (in curs). Presupune events deja sortate ascendent; daca nu, sorteaza defensiv dupa created_at. Intoarce sesiunile sortate descrescator dupa login_at.
3. `deriveTrafic(sessions: LoginSession[]): TraficProfil[]` — agrega per user_id: nr_sesiuni = count, timp_total_secunde = suma durata_secunde (ignora null). Sorteaza descrescator dupa timp_total_secunde.
Nu modifica logAuditEvent / fetchAuditLog existente.
