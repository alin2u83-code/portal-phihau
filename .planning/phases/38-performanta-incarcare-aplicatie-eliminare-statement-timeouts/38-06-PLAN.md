<objective>
Make every screen that needs attendance or trainings outside the startup window (today-90..today+30, D-03) ask for the full history explicitly, and wait for it where a wrong answer would write bad data.

Purpose: D-03 says the full history is requested explicitly from the reports. Planning found two more consumers where the window would be unsafe: Activitati and ProgramAntrenamenteManagement check conflicts against existing trainings before generating new ones, and the calendar browses arbitrary months. These are the only components reading filteredData.antrenamente from the shared context besides the dashboards (which use today's trainings, inside the window).
Output: six components, each with one hook call and a loading state.
</objective>
